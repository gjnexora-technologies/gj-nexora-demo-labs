## 💻 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/gjnexora-technologies/gj-nexora-demo-labs.git
cd gj-nexora-demo-labs
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file based on `.env.example`:
```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### 4. Run Development Server
```bash
npm run dev
```

## 🏗️ Production Build

```bash
npm run build
```

This compiles TypeScript and outputs an optimized bundle to `dist/`.

## 🌐 Deployment (Vercel)

This application is deployed on Vercel as a Single Page Application (SPA).

1. Connect the GitHub repository `gjnexora-technologies/gj-nexora-demo-labs` to Vercel.
2. In **Project Settings > Environment Variables**, configure:
   - `VITE_EMAILJS_SERVICE_ID`
   - `VITE_EMAILJS_TEMPLATE_ID`
   - `VITE_EMAILJS_PUBLIC_KEY`
3. Deploy with default build settings (`npm run build`, output directory `dist`).
